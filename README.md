## 功能

- [X] 允许玩家在游戏中与桌宠进行文字聊天。
- [X] 第三方 API 接入
- [X] 读取游戏内数据（包括球员信息，球队赛程，转会信息，战术布置等）
- [X] 根据游戏内的数据回复玩家内容

## Road Map

- [ ] Alpha 0.0.2 - 角色库，角色切换，实装 TTS 系统，修改界面；
- [ ] Alpha - 扩充读取覆盖与建议质量，完善滚动更新、配置迁移和故障恢复，加入不依赖新游戏接口的轻量娱乐互动；
- [ ] Beta - 接入 FMAPI，稳定读取接口；

**我们非常需要你的帮助，无论是提出功能，提供 BUG，提交 PR，这对我们是十分重要的，详见贡献指南。**
